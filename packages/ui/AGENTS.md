# UI Renova

Componentes reutilizáveis pertencem a este pacote; não importe apps, auth,
permissões, banco ou domínios de produto. Preserve tokens, foco, teclado e estados
desabilitados. React 19: use `ref` como prop ao criar componentes.

Fontes são arquivos locais de dependências Fontsource. Não introduza importação
CSS remota. Não adicione defaults de pessoas ou cargos. Configuração de gráficos
é código confiável, não entrada de usuários.

Rode `pnpm --filter @renova/ui test`, `pnpm --filter @renova/ui typecheck` e os
testes de navegador afetados. Veja [NOTICE.md](NOTICE.md) para a origem do código.
